# Jevio Unblocker

Android-приложение с двумя независимыми инструментами:

- локальный MTProto-прокси для Telegram;
- локальный DPI-desync VPN для сайтов и приложений.

Оба инструмента работают на устройстве. Трафик не отправляется через сервер разработчика. Для
Telegram можно дополнительно настроить собственный Cloudflare-домен или Worker, если прямой маршрут
заблокирован сетью.

## Скачать

Готовые APK публикуются на странице [Releases](https://github.com/xVerdy1337/tg-proxy-android/releases).
Скачайте последний APK и разрешите установку из неизвестных источников, если Android попросит об этом.

## Telegram-прокси

### Схема

```text
Telegram -> 127.0.0.1:1443 -> MTProto -> WebSocket/TLS -> Telegram DC
```

Приложение поднимает прокси только на loopback-интерфейсе телефона. После MTProto handshake оно
определяет дата-центр Telegram и выбирает рабочий маршрут: прямой WebSocket, Cloudflare или TCP
fallback.

### Быстрое подключение

1. Откройте вкладку **Telegram**.
2. Нажмите **Start proxy**.
3. Нажмите **Connect Telegram**. Приложение откроет Telegram с готовой ссылкой прокси.

Если Telegram не установлен или ссылка не открылась, скопируйте её из блока с секретом и откройте на
устройстве вручную.

### Ручная настройка

В Telegram откройте **Settings -> Data and Storage -> Proxy Settings** и добавьте MTProto-прокси:

- **Server:** `127.0.0.1`
- **Port:** `1443` (или порт, указанный в приложении)
- **Secret:** скопируйте из Jevio

Секрет сохраняется между запусками. При включённом Fake TLS после смены домена нужно добавить в
Telegram новую ссылку.

### Маршруты и настройки

- **Fake TLS** маскирует подключение под HTTPS к указанному домену и использует `ee`-secret.
- **Custom Cloudflare** позволяет указать свои домены, если встроенные маршруты не работают.
- **Cloudflare Worker** позволяет использовать собственный Worker без покупки домена. Инструкция:
  [docs/CfWorker.md](docs/CfWorker.md).

## Разблокировка сайтов

Вкладка **Sites** запускает локальный `VpnService`. Он перехватывает трафик выбранных приложений и
передаёт его через встроенный SOCKS5-движок ByeDPI. Внешний VPN-сервер не используется.

### Как пользоваться

1. Откройте вкладку **Sites**.
2. Нажмите кнопку включения и подтвердите системный запрос Android на VPN.
3. Выберите приложение или оставьте режим для всех приложений.
4. Запустите **Auto-tune**, если текущий метод не открывает сайты.

В настройках можно выбрать стратегию, заблокировать QUIC и исключить приложения, которым VPN мешает
(например, банки). Изменения метода и некоторых переключателей применяются после перезапуска VPN.

IPv4-трафик проходит через desync-релей. В настройках можно включить «Прямой IPv6»: тогда IPv6
оставляется вне IPv4-only TUN и идёт напрямую, что сохраняет связность в IPv6-only сетях. Если
переключатель выключен, IPv6 не выпускается напрямую. Отдельный IPv6 desync пока не используется.

Ручная проверка метода проверяет несколько прямых TLS-соединений. Она не является VPN-режимом и не
перехватывает трафик других приложений.

## Батарея и фоновые ограничения

Прокси работает как foreground service, поэтому Android может держать его запущенным при закрытом
экране. CPU wake lock не удерживается постоянно: он включается только при реальном relay-трафике,
остаётся до опустошения очереди исходящих WebSocket-данных и отпускается после короткого idle-периода.

Отдельный WebSocket heartbeat отключён: Telegram уже поддерживает idle-сессию своим MTProto
keepalive, поэтому прокси не будит радиомодуль каждую минуту на каждого клиента. Если маршрут
сломался, он переподключается при следующем реальном пакете.

Если производитель телефона агрессивно останавливает фоновые приложения, разрешите Jevio работу без
оптимизации батареи в системных настройках. Это отдельное разрешение Android и оно не требуется для
обычного запуска.

## Разрешения

- **VPN:** нужен только для вкладки Sites и запрашивается системным диалогом Android.
- **Notifications:** показывает статус foreground service на Android 13+.
- **Location:** используется только для привязки результатов Auto-tune к Wi-Fi-сети, если разрешение
  предоставлено.
- **Battery optimization:** необязательное исключение для устройств, которые завершают фоновые
  сервисы.

## Сборка

Требования:

- Android Studio Hedgehog или новее;
- JDK 17;
- Android SDK 35;
- NDK `25.1.8937393` и CMake `3.22.1`.

```bash
./gradlew assembleDebug
./gradlew assembleRelease
```

Debug APK подписывается автоматически. Release-сборка подписывается только при наличии переменных:

```text
KEYSTORE_PATH
KEYSTORE_PASSWORD
KEY_ALIAS
KEY_PASSWORD
```

Без них release APK создаётся неподписанным. CI workflow находится в [`.github/workflows`](.github/workflows).

## Архитектура

- `ProxyService` — foreground service локального Telegram-прокси;
- `MtProtoProxyServer` — MTProto handshake, выбор маршрута и relay;
- `WebSocketBridge` — WebSocket/TLS transport и bounded receive queue;
- `DesyncVpnService` — локальный TUN/VPN и маршрутизация потоков;
- `ByeDpiProxy` — JNI-обёртка над нативным ByeDPI;
- Jetpack Compose — основной интерфейс приложения;
- Quick Settings tiles — быстрое включение и выключение обоих сервисов.
