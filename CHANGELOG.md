# Изменения

Раздел текущей версии автоматически попадает в описание GitHub Release.

## 1.5.0

### Интерфейс

- На вкладках «Telegram» и «Сайты» горит точка, если сервис на этой вкладке включён.
- Кнопка включения вспыхивает и даёт короткую вибрацию в момент, когда сервис реально заработал.
  При системной настройке «Убрать анимацию» остаётся только вибрация.
- Статистика подписана понятнее: «Активные», «Успешные», «Неудачные», «Отправлено», «Получено».
  Время работы всегда показывается как `ч:мм:сс`.
- Кнопка «Подключить Telegram» переименована в «Добавить в Telegram».
- Режим «Все приложения» больше не пишет «исключено: 0».
- Выбранная вкладка сохраняется при повороте экрана.

### Telegram-прокси

- Прокси сам поднимает слушающий порт, если Android его закрыл, вместо того чтобы молча перестать
  принимать подключения.
- Большие загрузки в Telegram больше не рвут соединение: прокси ждёт, пока очередь отправки
  освободится, а не копит её в памяти.
- Успешно открытый WebSocket сам по себе больше не считается рабочим маршрутом, а отключение
  клиента не выкидывает рабочий маршрут из списка.
- Ошибки запуска прокси теперь видны в фильтре «Проблемы» журнала.
- Когда Android останавливает сервис прокси, порт освобождается сразу.

### Батарея

- Простаивающие сессии больше не будят процессор; keepalive-трафик Telegram держит его не дольше
  половины секунды.
- Статистика и таймер обновляются только пока экран приложения открыт, а не пока оно висит в
  недавних.
- VPN быстрее закрывает DNS-запросы и реже проверяет неактивные соединения.
- VPN больше не помечает подключение как лимитированное: приложения видят, лимитирована ли
  настоящая сеть.

### Разблокировка сайтов

- Если ByeDPI не запустился из-за занятого порта, приложение так и пишет вместо «start failed: no
  details».
